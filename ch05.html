第5章

Skill で手順を再利用する

Lv4 仕組みにする目安 3時間

毎回 AI に頼んでいる手順を「Skill」という形にまとめて、何度でも使えるようにします。

この章のゴール

  • Rules と Skill の違いが分かる
  • 簡単な Skill を1つ作り、次の周で使える

Rules と Skill の違い

Rules = いつも守る約束(AGENTS.md)
Skill = 決まった仕事をするときの手順

最初の Skill の例: check-before-finish

それまで毎回「テストして」「差分を見て」「spec.md を確かめて」と頼んでいたことを、1つの手順にまとめます。

「できました」と言う前に
1. intent.md と spec.md を読む
2. 変更したところ(差分)を見る
3. テストを実行する
4. エラーが出ていないか見る
5. spec.md の条件を1つずつ確かめる
6. 結果を報告する

やること

  1. 毎回頼んでいることを書き出す
  2. 手順として1つにまとめる
  3. Skill として置いてもらう。置き場は .agents/skills/<名前>/SKILL.md
  4. 先頭に「いつ使うか」の説明を書く。書いてあると、AI が自分で使います。名前を書いて頼めば確実に使います
  5. 次の周で実際に使う

良い頼み方を書く → 良い仕事のやり方を仕組みにする

権限(AI に渡す鍵)

読むだけ       → OK
ファイルを変える → 確認してから
危ないコマンド  → NG

Antigravity の権限は「毎回確認する」から始めています。慣れてきたら、決まった操作だけ自動で許可するように少しずつ増やします。増やすときは講師と相談します。

アプリの中で AI を使う人だけ

AI の答えの出来を測る仕組み(Eval)を足します。それ以外の人はテストだけで大丈夫です。
