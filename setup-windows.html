Windows 準備ガイド

AI と一緒にアプリを作る講座で使う道具とアカウントを準備します。先に自分の PC(ローカル)、次にインターネットの上(リモート)の順に進めて、終わったら「できた」に印を付けてください。

進み具合0 / 0

はじめに

必要なもの

  • Windows 10(64ビット)か Windows 11 の PC
  • 18歳以上であること(Antigravity の利用条件)
  • 40分くらいの時間(インストールの待ち時間を含む)

道具は2か所に分かれます

ローカル自分の PC

  • Antigravity … AI エージェント。PC のフォルダの中でファイルを作ったり直したりする
  • Chrome … 作ったページを開いて確かめる
  • Git … セーブ地点を残す
  • Node.js … テストを動かす(後の章)

リモートインターネットの上

  • GitHub … 作ったものを置いておく場所
  • ChatGPT … チャット型 AI。相談とレビューに使う。自分の PC の中には届かない

流れ(先にローカル、次にリモート)

  1. ローカルをそろえる: Google アカウント → 道具をまとめて入れる → Antigravity にログイン
  2. リモートをそろえる: GitHub アカウント → その名前とメールを Git に登録 → ChatGPT アカウント
  3. 入ったか確かめる

印はこの PC のブラウザにだけ残ります。パスワードは講師にも教えないでください。画面を共有しているときは、パスワードの入力を映さないようにします。

困ったとき




  「ERROR: winget was not found」と出る
  

    
    
      
  1. Microsoft Store の「アプリ インストーラー」を開き、「入手」か「更新」を押す
    2. 
      
  2. 準備用ファイルをもう一度ダブルクリックする
    3. 
      
  3. それでもだめなら、Windows Update をしてから PC を再起動する
    4. 
    

    
どうしても使えないときは、下の「公式サイトから手で入れる」で進めます。

  






  「git(node)という名前は認識されません」と出る
  

    
PowerShell と Antigravity を両方とも閉じて開き直してください。入れる前から開いていた画面は、新しく入った道具を見つけられません。それでもだめなら PC を再起動します。

  






  途中で赤い文字や「ERROR」「失敗」が出た
  

    
すでに入っているアプリは「既にインストールされています」と出ますが、問題ありません。

    
それ以外で止まったときは、黒い画面を閉じずに撮って講師に送ってください。メールアドレスが写っていたら、その部分は隠します。準備用ファイルは何回実行しても大丈夫です。

  






  公式サイトから手で入れる
  

    
    
      
  • Antigravity: antigravity.google/download(Windows の「Download for x64」)
    • 
      
  • Chrome: google.com/chrome
    • 
      
  • Git: git-scm.com/downloads/win(途中の選択肢はすべてそのまま「Next」で OK)
    • 
      
  • Node.js: nodejs.org/ja/download(「LTS」と書かれた方)
    • 
    

    
手で入れたときも、名前とメールの登録は手順5で同じようにします(PowerShell は開き直してから)。
