AI と一緒にアプリを作る講座

講座のもくじ

プログラミングをしたことがなくても、AI と一緒に自分の作りたいものを作れるようになる講座です。章ごとに「やること」と「できたらチェック」をまとめています。

この講座で目指すこと

ゴールは、自分の作りたいものを完成させることです。ただし AI に丸投げするのではなく、作りたいことを言葉にして、AI に作ってもらい、できたかを自分で確かめる。この流れを回しながら、1つずつ作っていきます。

回す輪はこの形です。最初から全部はやりません。章が進むごとに、1つずつ増やしていきます。

 ┌→ intent.md   作りたいこと・なぜ
 │     ↓
 │   spec.md     完成の条件
 │     ↓
 │   plan.md     作る順番
 │     ↓
 │   作る         小さく作って、動かして確かめる
 │     ↓
 │   テスト       完成の条件を満たしているか確かめる
 │     ↓
 │   PR レビュー  AI がコードを見て、自分は動きを確かめる
 │     ↓
 │   自動化       マージしたら自動でテスト・公開
 │     ↓
 └─ 振り返り     気づいたことを次の周へ

6つの段階

段階章できるようになること
Lv0 作ってもらう第1〜3章AI に頼んで、出てきたものを自分で開いて確かめる。Git でセーブして戻す
Lv1 言葉にする第4章作る前にやりたいことと完成の条件を言葉にし、輪を1周回す
Lv2 決めてから作る第4章条件と作る順番に納得してから作らせる。壊れたら材料を渡して調べさせる
Lv3 証拠で確かめる第4章テストと PR のレビューで確かめる。AI への約束を育てる
Lv4 仕組みにする第5章よく頼む手順を Skill にして、何度でも使えるようにする
Lv5 自動で回す第6〜7章テストと公開を自動で回し、作りたいものを完成させる

第4章は、1つの章の中で周を重ねて Lv1 → Lv2 → Lv3 と上がります。進む速さは人によって違って大丈夫です。各章の「できたらチェック」が全部できたら、次の章へ進みます。

章の一覧

第1章導入 — 学習環境をそろえる道具とアカウントをそろえて、AI と作業を始められる状態にします。この章ではまだ何も作りません。Lv0 作ってもらう第2章作りたいものを言葉にして、プロジェクトの説明書を作らせる作りたいものを言葉にして、AI に最初の仕事として「プロジェクトの説明書」を作ってもらいます。できたら GitHub に上げます。Lv0 作ってもらう第3章作りたいものを紹介するページを作らせ、Git でセーブするREADME.md に書いた作りたいものを、ブラウザで見られる紹介ページにしてもらいます。あわせて Git を「セーブ機能」として自分で使い、壊れたら前のセーブ地点に戻せるようにします。Lv0 作ってもらう第4章輪を回して、作りたいものを1機能ずつ作る作りたいものそのものを、1周に1機能ずつ作っていきます。作る前に相談役の ChatGPT と「何を作るか」を言葉にし、作ったら確かめて、振り返って次の周へつなぎます。周を重ねながら、Lv1 → Lv2 → Lv3 と上がっていきます。Lv1〜3 言葉にする → 証拠で確かめる第5章Skill で手順を再利用する毎回 AI に頼んでいる手順を「Skill」という形にまとめて、何度でも使えるようにします。Lv4 仕組みにする第6章自動テストと自動公開PR を出すたびにテストとレビューが自動で走り、マージしたら自動で公開される状態を作ります。あわせて、API キー(サービスを使うための合言葉)の作り方と守り方を学びます。Lv5 自動で回す第7章卒業制作 — 作りたいものを完成させるこの講座のゴールです。第2章で言葉にした作りたいものを、完成させます。作り方は第4〜6章と同じ輪で、細かい頼み方は自分で考えます。Lv5 自動で回す

ずっと守る約束

作ったものは GitHub(インターネット上の置き場)に上げます。あとで公開することもあるので、最初から次を守ってください。

  • 本名・住所・学校名や勤め先・電話番号・メールアドレス・顔写真を入れない(ニックネームで作る)
  • パスワードや API キー(サービスを使うための合言葉)をファイルに書かない。AI にも渡さない
  • 一緒に使う友だちなど、実在の人の名前を見本やテストに使わない(「A」「B」などの仮の名前にする)
  • 他の人が描いた絵・ゲームの画像・ロゴを勝手に使わない

AI は「できました」と言っても、本当にできているとは限りません。必ず自分で開いて確かめます。

講師を呼ぶとき

次のどれかに当たったら、進める前に講師に相談してください。

  • パスワード・API キー・ログインの仕組みを扱う
  • 個人情報を扱う、または公開する
  • お金がかかるサービスにつなぐ
  • 外にデータを送ったり、外から受け取ったりする機能を足す
  • 他の人が作った画像・絵・ロゴを使う
  • AI レビューの指摘を「直さない」と決めた
  • 段階(Lv)が上がるとき

分からない言葉が出てきたら、上の「ことば集」を見てください。
