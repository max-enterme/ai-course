# 雛形(テンプレート)

講座で、作る役の AI にそのまま取り込ませるファイルの置き場です。
**雛形にするのは「配管」だけです**(テストの準備・自動チェックの設定など、学ぶ対象ではなく、自分では正しいか確かめにくい部分)。作りたいものの画面・機能・説明書の中身は、雛形にせず、自分で AI に作らせます。

| 雛形 | いつ使うか | 中身 |
|---|---|---|
| [web-test/](web-test/README.md) | テストを入れる周(遅くとも Lv3 に上げるとき)。Web の題材 | テストの道具の設定と、見本のテスト1本 |

使い方は、それぞれのフォルダの README.md にあります(AI への頼み方と、取り込んだあとに自分で確かめること)。
