第3章

作りたいものを紹介するページを作らせ、Git でセーブする

Lv0 作ってもらう目安 3時間

README.md に書いた作りたいものを、ブラウザで見られる紹介ページにしてもらいます。あわせて Git を「セーブ機能」として自分で使い、壊れたら前のセーブ地点に戻せるようにします。

この章のゴール

  • 作りたいものを紹介するページを AI に作らせ、ブラウザで開いて見られる
  • 変える前と後を並べて、何が変わったかを自分の言葉で言える
  • 頼んでいないところが変わっていないかを、画面と Git の差分で確かめられる
  • 差分を見て commit し、GitHub に送れる
  • 壊れた状態から、前のセーブ地点に戻せる

なぜ「紹介ページ」なのか

作りたいものは人によって違い、画面のあるものとは限りません(PC で動く道具・決まった作業を自動でするもの など)。紹介ページなら、何を作る人でも同じ課題で「見えるものを作らせて、確かめる」を練習できます。作りたいものそのものは、次の第4章から作ります。

  • 置き場は docs/ フォルダです(作るもの本体と混ざらないようにするため)
  • 中身は README.md に書いたことだけにします。書いていないことは足させません

場所を指すための言葉

書けるようになる必要はありません。AI に「どこを」直してほしいかを伝えるときに使います。

HTML       = 内容(画面に出るもの)
CSS        = 見た目(色・大きさ)
JavaScript = 動き(押したら何が起きるか。紹介ページでは使いません)

Git で覚える4つ

ことば一言で
リポジトリセーブを管理しているフォルダ
commitセーブ
差分何が変わったか
履歴セーブの一覧

第2章から AI に commit と push を頼んできました。この章では、差分と履歴を自分で見て、壊れたら戻します。Antigravity の Git の画面から操作するので、コマンドは覚えなくて大丈夫です。

やること

  1. 紹介ページを作ってもらう(約束は AGENTS.md にあるので、頼み方は短くて大丈夫です)
README.md に書いた作りたいものを紹介するページを、docs/ に作ってください。
README.md に書いてあることだけを使い、書いていないことは足さないでください。
作ったら、どのファイルに何を書いたかを初心者向けに説明してください。
  1. docs/index.html をブラウザで開いて、自分で見る
    • ファイルが docs/ の中に、index.html と style.css の2つだけか
    • ライブラリ(追加の部品)が入っていないか
    • README.md に無いことがページに出ていないか
  2. commit する(最初のセーブ地点)
  3. 「見出しを○○にしてください」「背景を○色にしてください」と 1つずつ 頼み、毎回、前と後を見比べる
  4. 変えたあと、AI に説明してもらう
今の変更で、何をどう変えたのかを初心者向けに説明してください。
画面のどこが変わったかを先に教えてください。
  1. 何が変わったかを 自分の言葉で 言う。Git の差分も見て、頼んでいないところが変わっていないかを確かめる
  2. commit して GitHub に送る(送るのは AI に頼んでも大丈夫です)
  3. わざと大きく変えさせて壊す → 3 のセーブ地点に戻す
  4. GitHub の画面で docs/ のファイルと履歴を見る

約束が守られていなかったら

まず「AGENTS.md のどの約束を守っていないか」を AI に言ってもらい、消して作り直してもらいます。それでも同じなら、新しい会話で約束を3つ言わせて(第2章の確かめ方)、AI が約束を読んでいるかを見ます。「約束したのに違うものが出た」は大事な発見なので、講師に見せてください。

Git がうまく動かないとき

Git の名前とメールアドレスは第1章で登録してあります。まだなら準備ページで登録してから、Antigravity を起動し直します。AI に Git を入れさせると行き詰まりやすいので、困ったら講師に聞いてください。

やってみよう(任意)

1行だけ、AI を使わずに自分で変えてみます(見出し・背景色など)。できなくても大丈夫です。変えたら、差分に出ることも見てください。

これからずっと守ること

大きな変更の前に commit する。

戻れる場所があれば、AI に大きく任せても怖くありません。

約束

紹介ページは、あとで人に見せたり公開したりすることがあります。

本名・住所・学校名や勤め先・電話番号・メールアドレス・顔写真を入れない。他の人の名前や、他の人が描いた絵・ゲームの画像を勝手に使わない。
