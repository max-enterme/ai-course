もくじ ことば集

第1章

導入 — 学習環境をそろえる

Lv0 作ってもらう目安 2時間

道具とアカウントをそろえて、AI と作業を始められる状態にします。この章ではまだ何も作りません。

この章のゴール

  • 道具の地図を見て、ローカル(自分の PC)とリモート(インターネットの上)にそれぞれ何があるかを言える
  • 道具を入れて Antigravity を起動し、自分で作った空のフォルダを開ける
  • GitHub と ChatGPT にログインできる
  • Antigravity と ChatGPT が、それぞれどこに手が届くかを言える

道具の地図

道具は2か所に分かれます。先にローカル、次にリモートの順にそろえます。

道具場所何に使うか
AntigravityローカルAI エージェント。PC のフォルダの中でファイルを作ったり直したりする
ChromeローカルAI が自分で画面を開いて確かめるときに使う
Gitローカルセーブ地点を残す(第2章から AI に頼み、第3章で自分で使う)
Node.jsローカルテストを動かす(第4章)
GitHubリモート作ったものを置いておく場所(第2章から)
ChatGPTリモート何を作るかを一緒に詰める相談役(第4章から)

やること

Windows の人は、準備ページ Windows 準備ガイド を開いて、上から順に進めてください。ページも同じ順番です。

ローカル(自分の PC)

  1. Google アカウントを確かめる。なければ作る(Antigravity のログインに使います)
  2. Antigravity・Chrome・Git・Node.js を入れる
  3. Antigravity にログインする。権限は「毎回確認する」(Request Review)にしておく
    • AI がファイルを変える前に、何をするかを見られるようにするためです
  4. 空のフォルダを自分で作り(例: デスクトップに mysite)、Antigravity で開く
    • 第2章はこのフォルダから始めます

リモート(インターネットの上)

  1. GitHub のアカウントを作り、「メールアドレスを公開しない」で使う noreply のメールアドレスを控える
  2. GitHub のユーザー名と noreply のメールアドレスを Git に登録する
    • セーブ(commit)には名前とメールアドレスが残ります。本当のメールアドレスが見えないように、noreply のほうを使います
  3. ChatGPT にログインできるようにしておく(GitHub とつなぐのは第4章です)

パスワードは自分で入れます

アカウントを作るときやログインのパスワードは、講師にも AI にも教えないでください。画面を共有しているときは、入力を映さないようにします。

AI は「手が届く場所」でしか仕事ができない

  • Antigravity はローカルにいます。 自分の PC のフォルダの中でファイルを作る・直す・消すことができ、作ったものを動かして確かめられます
  • ChatGPT はリモートにいます。 GitHub とつなぐと、そこにあるものを読んだり書き込んだりできます。でも自分の PC の中には届かないので、動かして確かめることはできません
  • だから、ChatGPT に見せたいものは先に GitHub へ送ります。送る道具が Git です

AI は「できました」と言っても、本当にできているとは限りません。次の章から、自分で開いて確かめます。

次の章までに考えてくること

次の章の最初に、作りたいものを講師と話します。作り方は考えなくて大丈夫です。

  • 誰が使うか。いつ・どこで使うか
  • 何をしたら、何が出たら嬉しいか
  • 今はどうしていて、何が面倒か

思いつかなければ、ToDo アプリ(やることの一覧)で進めます。
