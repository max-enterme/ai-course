第7章

卒業制作 — 作りたいものを完成させる

Lv5 自動で回す目安 完成まで

この講座のゴールです。第2章で言葉にした作りたいものを、完成させます。作り方は第4〜6章と同じ輪で、細かい頼み方は自分で考えます。

この章のゴール

  • 自分の作りたいものの「完成」を、自分で決められる
  • 完成の条件を、全部満たすところまで作れる
  • 「誰が・いつ使うか」に書いた場面で、実際に使える

「完成」を決める(最初に)

  1. README.md の最終像を、講師と一緒に読み直す
  2. 講座の時間で作りきれない大きさなら、講座の中で完成とする範囲 を決める(外のサービスにつなぐ部分は手で入れる形にする・画面を減らす など)。外した部分は README.md の「やらないこと」か「完成のあとにやりたいこと」に移す
  3. 相談役と、完成の条件を決める。機能を「必ず / できれば / 余裕があれば」に分け、「必ず」が全部できたら完成 とする
  4. 完成の条件を README.md に書いてもらい、push する

完成の条件には、「誰が・いつ使うか」に書いた場面で、実際に使ってみて困らない ことを必ず入れます。

流れ

段階やること残るもの
完成を決める上の1〜4README.md の「完成の条件」
周を回す「必ず」の残りを、1周1機能で作る(第4章の形。テスト・AI レビュー・自動テスト・Skill はそのまま使う)specs/・PR・テスト
使ってみる使う場面で、自分で実際に使う。困ったことは次の周にする次の周の intent.md
仕上げ使い方を README.md に書いてもらう(はじめての人が使い始められるように)。公開する人は公開するREADME.md の「使い方」(公開する人は公開 URL)
振り返り下の6つを講師に話す完成のあとにやりたいこと・AGENTS.md・Skill

次の周を決めるときは、相談役に「次の周を詰めてください」と送れば、README.md の「完成の条件」のうち、まだできていないものから一緒に選んでくれます。

振り返りの6つ

  1. 完成したもので、何ができるようになったか(使ってみてどうだったか)
  2. AI がうまくやったこと / 失敗したこと
  3. なぜ失敗したと思うか
  4. どんな頼み方で良くなったか
  5. AGENTS.md・Skill に何を足したか
  6. 完成のあとに、次にやりたいこと

最後にそろっているもの(全部、自分のリポジトリに)

  • 完成したもの
  • README.md(最終像・完成の条件・使い方)
  • specs/ の intent.md / spec.md / plan.md と、PR の履歴(AI レビューとその対応)
  • テストと自動テストの結果(公開する人は公開 URL)
  • AGENTS.md と Skill
